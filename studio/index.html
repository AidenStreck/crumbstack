How ideas become games

  1. Idea. A one-line pitch.
  2. Prototype. A playable web version in a few days.
  3. Testing. Friends and short TikTok clips. Do people come back?
  4. Launching. Only the winners go to the App Store.

Most ideas should get dropped. Testing many small games cheaply is how studios find their hits.
